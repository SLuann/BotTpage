# Política de Privacidade A sua privacidade é muito importante para nós. Esta Política de Privacidade explica como o VerifyL0 ("Aplicativo") coleta, utiliza e protege as suas informações ao ser utilizado no Discord. ## 1. Informações que Coletamos Para funcionar corretamente, o Aplicativo pode acessar e processar as seguintes informações fornecidas publicamente pela API do Discord: - IDs de usuário, IDs de servidor (guilds) e IDs de canais. - Nomes de usuário, tags e avatares. - Conteúdo de mensagens (apenas quando comandos específicos são invocados ou necessários para as funções principais do Aplicativo). ## 2. Como Usamos as Informações As informações coletadas são utilizadas exclusivamente para: - Executar os comandos e funcionalidades solicitados pelos usuários. - Manter configurações personalizadas do Aplicativo para o seu servidor. - Garantir a segurança e prevenir abusos dentro do sistema. ## 3. Compartilhamento de Dados Nós **não** vendemos, trocamos ou transferimos seus dados de identificação pessoal para terceiros. Os dados permanecem estritamente dentro da nossa infraestrutura de hospedagem e são acessados apenas pelo Aplicativo. ## 4. Retenção e Exclusão de Dados Os dados são armazenados apenas pelo tempo necessário para fornecer os serviços. Se você deseja que seus dados ou os dados do seu servidor sejam removidos do nosso banco de dados, entre em contato conosco ou remova (kick) o Aplicativo do seu servidor.
